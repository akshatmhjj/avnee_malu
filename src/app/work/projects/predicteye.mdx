## Overview

Portfolio Risk Doctor is an interactive portfolio risk and analytics application built with Python and Streamlit. Users can enter holdings and portfolio weights to retrieve historical market data, evaluate portfolio behaviour, compare performance with a benchmark, and understand the sources of portfolio risk.

Rather than relying on a black-box model, the application uses an interpretable, rules-based diagnostic engine. Each portfolio health insight is linked to calculated metrics, making the analysis transparent and easier to review.

> This project is designed for educational analysis and does not provide investment advice or trading recommendations.

## Analysis Included

### Performance and Risk-Adjusted Returns

- Total return and annualized return (CAGR)
- Annualized volatility
- Sharpe ratio and Sortino ratio
- Maximum drawdown and drawdown history
- Portfolio beta relative to a selected benchmark

### Downside Risk and Diversification

- Historical Value at Risk (VaR)
- Conditional Value at Risk (CVaR / Expected Shortfall)
- Parametric VaR comparison
- Correlation matrix and average portfolio correlation
- Herfindahl-Hirschman Index (HHI) and effective holdings
- Marginal and component contribution to portfolio risk by holding

### Technical Analysis

For each selected asset, the application calculates:

- Simple Moving Averages (SMA 20, 50, and 200)
- Relative Strength Index (RSI 14)
- MACD and signal-line analysis
- Bollinger Bands

These indicators are presented as market-behaviour descriptors, not buy or sell signals.

### Stress Testing

The application evaluates portfolio exposure under adverse market scenarios, including:

- Beta-adjusted market crash scenario
- Severe market-stress scenario
- Technology-sector selloff
- Custom market-shock scenario

Each scenario reports estimated portfolio return, profit and loss, ending value, and each holding’s contribution to the loss.

## Portfolio Health Score

Portfolio Risk Doctor generates a transparent 0–100 Portfolio Health Score using volatility, drawdown, VaR, stress losses, concentration, and correlation. The score is accompanied by plain-language diagnostics such as concentration risk, elevated downside exposure, diversification strength, and market-beta sensitivity.

## Decision Value

A portfolio can produce attractive returns while still carrying concentrated exposure, elevated volatility, correlated holdings, or significant downside risk. This project brings performance, risk, diversification, and stress-test measures into a single repeatable workflow, helping users assess both upside participation and downside behaviour.
